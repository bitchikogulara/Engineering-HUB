Engineering Hub

Design system + screen mockups · handoff to Tailwind + shadcn/ui

An internal web app for the 2-person Transporter Group engineering department — a Kanban board, weekly objectives, and an AI meeting assistant that proposes tasks and decisions for a human to confirm. A precise instrument, dense but breathable, dark-first for workshop evenings, and built to scale gracefully to ~10 people.

IBM Plex Sans / Mono Blocked = loudest AI marker throughout Light + dark · 1440 + 390 WCAG AA · color never the only signal

Static, self-contained HTML + CSS. Every page links only tokens.css and base.css. The only JavaScript is the theme toggle (persisted in localStorage) and trivial state demos. All colors resolve through tokens — tokens.css maps 1:1 onto shadcn/Tailwind variables and is meant to be consumed directly by the implementation. See NOTES.md for per-screen rationale.
